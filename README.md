# Leopoldo · Gran Pesca di Natale

Gioco di pesca "regalo brutto" (HTML5 canvas, zero dipendenze). Si apre `index.html` e si gioca.

- **Comandi**: tieni premuto (spazio / mouse / touch) per caricare il lancio, rilascia per lanciare; all'abbocco premi subito; durante il recupero tieni premuto per far salire il pesce nella zona.
- **ANSIA**: se arriva al 100% è crisi e referto medico. Scopri tutti i 21 oggetti del Pescadex per il certificato finale.
- File: `index.html`, `items.js` (catalogo oggetti), `pesca.js` (gioco).
- Il vecchio platformer "LUCA e la Moka Rubata" è in `/platformer/`.

Deploy: Vercel, statico, aggiornato a ogni push su `main`.
